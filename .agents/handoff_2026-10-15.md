## Aturan yang wajib dipatuhi

- Perbaiki bug di lokal dulu. Jangan push, tag, atau deploy kecuali mas yang
  minta. Semua perubahan di VPS dikerjakan mas sendiri.
- Migrasi hanya ditulis dan dijalankan dari `app_laravel`:
  `docker exec laravel-app php artisan migrate --force`. Jangan pernah migrate
  dari unit-apps.
- Jangan jalankan `php artisan test`, karena phpunit menulis ke `ubmi_db`.
- Uji tulis ke DB hanya di dalam transaksi yang di-rollback
  (`DB::beginTransaction(); ... DB::rollBack();`).
- Tinker ke `ubmi_db` ditolak classifier auto-mode ("Production Reads").
  Berikan perintah read-only ke mas supaya dia yang menjalankan.
- Jangan pakai `open(p,'w').write(f(open(p).read()))` di Python. Baca dulu ke
  variabel, baru tulis. `Sidebar.jsx` pernah terhapus gara-gara pola itu.
- `routes/web.php` dan `resources/js/Components/Sidebar.jsx` berisi perubahan
  mas yang BELUM di-commit. Stage hanya hunk sendiri lewat index blob:
  `git show :file | transform | git hash-object -w --stdin`, lalu
  `git update-index --cacheinfo 100644,<blob>,<file>`.
- Jangan commit berkas fitur mas yang belum di-commit tanpa izin dia:
  - `app/Http/Controllers/{TbContribution,BopContribution,SkswUnit,VehicleAsset}Controller.php`;
  - model `Saving*`, `Tb*`, `Ops*`, `Inv*`;
  - halaman `Pages/Tabungan`, `Pages/Sksw`, `Pages/Assets`;
  - semua `.agents/*.md`, termasuk berkas ini.
- Jangan commit `public/build/*` dan `bootstrap/ssr/*`. CI yang build.
- Mas masih develop dan HMR jalan. Jangan ingatkan `npm run build` tiap edit.
- Bahasa ke mas: Indonesia, panggil "mas", asisten bernama Muvita. Jangan
  yes-man; kritik flow yang jelek dengan alasan.

## Cara deploy (hanya kalau mas minta)

Staging, dari branch `sync/branch-scoping-and-agregasi-docs`:

```bash
git push -q origin HEAD && git tag v1.0.X && git push -q origin v1.0.X
```

Production: `git tag prod-v1.0.X v1.0.X && git push -q origin prod-v1.0.X`.
Pantau dengan `gh run watch <id> --exit-status`. Kalau job gagal karena error
ingest containerd, jalankan `gh run rerun <id> --failed`.

Kalau rilis butuh migrasi `app_laravel`: deploy `app_laravel` dulu, lalu mas
migrate di `app_laravel-php`, baru deploy unit-apps.
